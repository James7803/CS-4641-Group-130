This is a clone of the repo of my course project, Brain Tumor Classification.

# Brain Tumor Classification Project

## All directories and files related to the contents of the project:

* `/_layouts/`
    - `default.html`: The template file for the project website page.
* `/script/`
    - `index.html`: The html file for the project website page.
* `/src/`
    - `dataset/`: Contains the training and testing brain tumor data (both the original images and the NumPy array files generated by `Preprocessing.py`) organized by categories (glioma, meningioma, notumor, pituitary).
    - `images/`: Contains the traning and testing brain tumor data (only the original images).
    - `brain_tumor_cnn.pth`: The trained PyTorch model weights.
    - `NN.ipynb`: Jupyter notebook that trains a 3-layer CNN, saves `brain_tumor_cnn.pth`, and reports accuracy, confusion matrices, and confidence statistics.
    - `Preprocessing.py`: The data preprocessing script.
* `index.md`: Contains the Markdown contents of the project website page.
* `/assests/`
    - `images/`: Contains images used for figures on the website.
